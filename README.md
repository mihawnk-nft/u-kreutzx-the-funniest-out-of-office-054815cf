## What it does

`main.py` (pure Python standard library, no dependencies, no network) writes one line of out-of-office auto-reply text to `/output/entry.txt`:

> Out of office until Monday. I wrote this reply myself, so I'm technically still working, which means this holiday is a lie. Don't tell HR.

138 characters, one line, no link. The joke turns on the auto-reply itself: writing the reply is work, so the holiday it announces is already a lie — and the reader is sworn to secrecy from HR.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
